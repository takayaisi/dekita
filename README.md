# まいにち できた！

iPad・iPhone向け、サーバー処理不要のWebアプリ。2人の切り替え、毎日のチェック、星、ご褒美の交換、親用の簡易暗証番号、バックアップに対応。

## 無料で公開する

1. GitHubの無料アカウントで、空の **Public** リポジトリを作成します。例：`dekita`。
2. このフォルダーの中身をリポジトリのルートへアップロードします。index.htmlが直下になる形です。子供の名前・写真やバックアップファイルはアップロードしないでください。
3. リポジトリの Settings → Pages → Source を **GitHub Actions** にします。
4. `.github/workflows/pages.yml` もアップロード済みなら、Actions → Publish app to GitHub Pages → Run workflow を実行します。以後mainブランチへの更新で自動公開されます。
5. `.github`フォルダーをアップロードできない場合は、GitHubの Add file → Create new file で `.github/workflows/pages.yml` を作り、付属ファイルの内容を貼り付けてください。
6. 成功後、Settings → Pages に表示されるURLをSafariで開きます。

GitHub Pagesのサイトとコードは公開されます。個人の記録はブラウザ内にのみ保存され、サイトへ送信しません。GitHub無料プランの標準のPagesとActionsを使い、有料プラン・独自ドメインは不要です。

## iPad・iPhoneに置く

公開URLをSafariで開き、共有メニュー → ホーム画面に追加。端末のOSによっては「Webアプリとして開く」をオンにします。初回は通信が必要です。オフライン準備後は通信なしでも起動できます。

## 最初の設定

「おうちのひと」を押して数字4けたの暗証番号を設定。名前、やること、ご褒美を変更します。設定を保存して子供に渡してください。星の交換も親用画面から行います。

## 保存と制限

- 毎日のチェックは端末の現地時刻で日付が変わると切り替わります。星は持ち越します。同じ項目は当日に1度のみ加算。達成後の取り消しは未実装です。
- iPad・iPhoneの記録は別々です。同期・アカウント・通知・育成ゲームは未実装。木の見た目は保有する星数で変わります。
- ブラウザのデータ削除などで記録を失うことがあります。親用画面から定期的にバックアップしてください。Safariとホーム画面版で保存領域が異なる場合があるため、ホーム画面版で継続利用してください。
- 暗証番号は子供の誤操作対策です。端末にアクセスできる人への厳密なセキュリティ境界ではありません。バックアップには暗証番号のハッシュも含まれます。
- 暗証番号を忘れた場合、端末のサイトデータを削除すると初期化されます（記録も消えます）。必要なら事前に相談してください。
- 更新時はsw.jsのCACHE名を新しい値に変えてください。新しいバージョンが準備できたらアプリ内に更新ボタンが表示されます。端末内の記録は同じURLで引き継ぎます。

## 技術

HTML/CSS/JavaScriptのみ。外部ライブラリや広告・アクセス解析なし。HTTPSで配信してください。ローカル確認はlocalhostのHTTPサーバーを使い、HTMLの直接ダブルクリックは避けてください。
